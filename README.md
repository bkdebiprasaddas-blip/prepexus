# PREPEXUS - Student Study Tracker

PREPEXUS is a web-based Student Study Tracker developed using PHP and MySQL.

It helps students organize subjects, plan study tasks, manage study materials, and track their study progress.

## Features

- User Registration
- User Login
- Dashboard
- Subject Management
- Study Planner
- Study Materials
- Progress Tracker
- Profile Management
- Logout
- CRUD Operations
- User-specific data
- MySQL Database

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- phpMyAdmin

- XAMPP
- PHP

- Git

## Installation

### 1. Clone the repository

Clone the repository inside:

C:\xampp\htdocs\

### 2. Start XAMPP

Start:

- Apache
- MySQL

### 3. Create the database

Open:

http://localhost/phpmyadmin

Create a database named:

prepexus

### 4. Import the database

Select the `prepexus` database and import:

prepexus.sql

### 5. Check database configuration

Open:

config/database.php

Make sure the database name is:

prepexus

### 6. Run the project

Open:

http://localhost/prepexus/
